ba.bayesian.priors

Prior construction helpers for Beta and Dirichlet distributions.

ba.bayesian.priors.from_counts(successes: int, failures: int) → tuple[float, float][source]

‘Imaginary data’ framing: Beta(successes + 1, failures + 1).

“Think of the prior as having already seen these imaginary outcomes.”

>>> from_counts(2, 8)
(3, 9)
ba.bayesian.priors.from_mean_kappa(mean: float | ndarray, kappa: float) → ndarray[source]

Construct prior from mean and concentration (κ = α + β).

κ = 2 gives uniform; κ = 50 gives a strongly informative prior. The “equivalent sample size” is κ.

>>> from_mean_kappa(0.3, 10)
array([3., 7.])
>>> from_mean_kappa(0.5, 2)
array([1., 1.])
ba.bayesian.priors.from_quantiles(q1: float, p1: float, q2: float, p2: float) → tuple[float, float][source]

Solve for Beta(α, β) matching P(θ < q1) = p1 and P(θ < q2) = p2.

Uses least-squares minimization in log-space for numerical stability.

>>> a, b = from_quantiles(0.2, 0.05, 0.6, 0.95)
>>> 1.0 < a < 10.0
True
ba.bayesian.priors.jeffreys(k: int = 2) → ndarray[source]

Jeffreys prior: Dirichlet(0.5, …, 0.5).

For k=2, this is Beta(0.5, 0.5).

>>> jeffreys()
array([0.5, 0.5])
>>> jeffreys(3)
array([0.5, 0.5, 0.5])
ba.bayesian.priors.resolve_prior(prior: str | tuple | ndarray | None, k: int = 2) → ndarray[source]

Resolve a prior specification to a Dirichlet parameter array.

Accepts:

  • ‘jeffreys’, ‘uniform’, ‘haldane’

  • ‘beta(a,b)’ for k=2

  • tuple (a, b) for k=2

  • numpy array of length k

>>> resolve_prior('jeffreys')
array([0.5, 0.5])
>>> resolve_prior('beta(2,3)')
array([2., 3.])
>>> resolve_prior((1, 1))
array([1., 1.])
ba.bayesian.priors.uniform(k: int = 2) → ndarray[source]

Uniform (Bayes-Laplace) prior: Dirichlet(1, …, 1).

For k=2, this is Beta(1, 1).

>>> uniform()
array([1., 1.])
