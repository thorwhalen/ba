ba.bayesian.sensitivity

Prior sensitivity analysis for Bayesian inference on contingency tables.

ba.bayesian.sensitivity.sensitivity(ct: ContingencyTable, *, priors: tuple[str, ...] | list[str] = ('jeffreys', 'uniform', 'beta(2,2)'), n_mc: int = 100000, ci_prob: float = 0.95) → DataFrame[source]

Compute posterior under multiple priors and compare.

Returns a DataFrame with one row per prior, showing posterior means, credible intervals, data weight, and flags for prior influence.

Flags:

prior_influenced: data_weight < 0.8 prior_dominated: data_weight < 0.5

>>> from ba.core.contingency import ContingencyTable
>>> ct = ContingencyTable.from_counts(7, 3, 2, 8)
>>> df = sensitivity(ct)
>>> len(df) == 3
True
>>> 'data_weight' in df.columns
True
