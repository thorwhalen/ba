ba.rules.mining

Association rule mining with optional Bayesian augmentation.

ba.rules.mining.mine(data: DataFrame, *, min_support: float = 0.1, min_confidence: float = 0.5, outcome: str | None = None, appearance: dict | None = None, algorithm: str = 'auto', measures: tuple[str, ...] = ('support', 'confidence', 'lift'), max_len: int = 3, bayesian: bool = True, prior_alpha: float = 0.5, prior_beta: float = 0.5, ci_prob: float = 0.95) → DataFrame[source]

Mine association rules from a DataFrame.

Parameters:

  • data – Input DataFrame (binary or categorical columns).

  • min_support – Minimum support threshold.

  • min_confidence – Minimum confidence threshold.

  • outcome – If given, constrain RHS to items containing this column name.

  • appearance – Dict with keys 'rhs', 'lhs', 'none' mapping to lists of item names for constrained mining.

  • algorithm – Itemset mining algorithm (see mine_itemsets).

  • measures – Tuple of measure names to compute.

  • max_len – Maximum rule length (LHS + RHS items).

  • bayesian – If True, append credible interval columns.

  • prior_alpha – Beta prior alpha for Bayesian CIs.

  • prior_beta – Beta prior beta for Bayesian CIs.

  • ci_prob – Credible interval probability.

Returns:

antecedents, consequents, and requested measures (plus CI columns if bayesian=True).

Return type:

DataFrame with columns

>>> import pandas as pd
>>> df = pd.DataFrame({
...     'A': [1,1,0,0,1,1,0,1],
...     'B': [1,0,1,0,1,1,0,0],
...     'Y': [1,1,0,0,1,1,0,0],
... })
>>> rules = mine(df, min_support=0.2, min_confidence=0.5)
>>> 'antecedents' in rules.columns
True
