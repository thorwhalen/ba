ba.rules.encoding

Transaction encoding for association rule mining.

ba.rules.encoding.to_transactions(df: DataFrame, *, binary_as_presence: bool = True, include_negation: bool = False) → DataFrame[source]

Convert a DataFrame to a boolean transaction DataFrame.

Each variable-value pair becomes a column (item). Binary columns become presence items; categorical columns become one item per level.

Parameters:

  • df – Input DataFrame with binary or categorical columns.

  • binary_as_presence – If True, binary columns map 1 → item present.

  • include_negation – If True, add negated items for binary columns (e.g., ~smoking when smoking=0).

Returns:

Boolean DataFrame where each column is an item and each row is a transaction.

>>> import pandas as pd
>>> df = pd.DataFrame({'color': ['red', 'blue', 'red'], 'big': [1, 0, 1]})
>>> trans = to_transactions(df)
>>> sorted(trans.columns.tolist())
['big', 'color=blue', 'color=red']
>>> trans['big'].tolist()
[True, False, True]
