ba.core.contingency

Contingency tables: the universal input for all ba analyses.

class ba.core.contingency.ContingencyTable(counts: ndarray, row_var: str, col_var: str, row_labels: tuple[str, ...] = (), col_labels: tuple[str, ...] = ())[source]

An r×c contingency table with metadata.

The universal input for all analyses in ba. Wraps an r×c numpy array of integer counts with variable names and level labels.

>>> ct = ContingencyTable.from_dataframe(
...     pd.DataFrame({'X': [1,1,0,0,1], 'Y': [1,0,1,0,1]}), 'X', 'Y'
... )
>>> ct.n
5
>>> ct.is_2x2
True
