ba.qca.minimize.minimize(tt: DataFrame, *, outcome_col: str = 'OUT', conditions: list[str] | None = None, include: str = '1', method: str = 'qmc') → QCASolution[source]

Minimize a truth table using Quine-McCluskey.

Parameters:

  • tt – Truth table (output of ba.qca.truth_table).

  • outcome_col – Column marking positive (1), negative (0), or don’t-care (‘C’/’?’) rows.

  • conditions – Condition column names. If None, inferred as all columns except outcome_col, n, consistency, flag.

  • include – Which rows to include as positive: '1' = only positive rows; '?' or 'C' = also include don’t-care/remainder rows.

  • method – 'qmc' for Quine-McCluskey (only option currently).

Returns:

QCASolution with minimized Boolean expression.

>>> import pandas as pd
>>> tt = pd.DataFrame({
...     'A': [0, 0, 1, 1], 'B': [0, 1, 0, 1],
...     'OUT': [0, 1, 1, 1], 'n': [3, 2, 2, 4],
...     'consistency': [0.0, 1.0, 1.0, 1.0], 'flag': ['', '', '', ''],
... })
>>> sol = minimize(tt)
>>> 'A' in sol.expression or 'B' in sol.expression
True
